MRSPTU CampusFind - Supabase Connection Setup

1. Open assets/js/supabase-config.js.
2. Replace PASTE_YOUR_PROJECT_URL_HERE with the Supabase Project URL.
3. Replace PASTE_YOUR_PUBLISHABLE_KEY_HERE with the Supabase Publishable key (sb_publishable_...).
4. Do NOT use a Secret key or service_role key in this file.
5. In Supabase SQL Editor, run the migration below to make the status values match the website.
6. In Supabase Authentication > URL Configuration, add your deployed Netlify URL to Site URL and Redirect URLs.
   Add http://localhost:5500/** as a redirect URL while testing with VS Code Live Server.
7. Test registration/login, report submission, photo upload, search, and My Reports.

SQL migration (run once):

ALTER TABLE public.items DROP CONSTRAINT IF EXISTS items_status_check;
ALTER TABLE public.items ADD CONSTRAINT items_status_check CHECK (status IN ('Open', 'Returned', 'Closed'));
ALTER TABLE public.items ALTER COLUMN status SET DEFAULT 'Open';

NOTE: Existing storage policies and the items table were created in the Supabase dashboard during setup.
The browser uses only the Publishable key and relies on Row Level Security policies.
